# 📊 Zerodha Kite Dashboard Clone

A **full-stack trading dashboard** inspired by the Zerodha Kite platform, designed to simulate real-world stock portfolio tracking with a modern UI and modular backend architecture.

This project demonstrates **production-level application structure**, data handling, and dashboard interface design similar to professional trading platforms.

## 🚀 Project Overview

Modern trading platforms require:

✔ Real-time portfolio visibility  
✔ Structured data representation  
✔ Scalable backend architecture  
✔ Clean and responsive UI  
✔ Modular feature organization  

This project replicates these concepts through a **multi-module full-stack implementation**.

## ⚙ Local Setup & Installation

### 1️⃣ Clone Repository
```bash
git clone https://github.com/abdul-kheeyan/ZerodhaClone.git
cd ZerodhaClone
```

### 2️⃣ Install Backend Dependencies
```bash
cd backend
npm install
```

### 3️⃣ Start Backend Server
```bash
npm start
```

### 4️⃣ Run Frontend / Dashboard
Open `frontend` or `dashboard` folder using:

- Live Server (VS Code)  
OR  
- Your configured build setup
